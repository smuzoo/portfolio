# Портфолио Петра Овчинникова / smuzoo

Статический сайт для GitHub Pages. Не требует ChatGPT, базы данных или сборки.

## Размещение

1. Создать публичный репозиторий portfolio.
2. Загрузить содержимое этой папки в корень репозитория: index.html, styles.css, app.js, content.js, portfolio.pdf, assets/ и .nojekyll. ZIP-архив предварительно распаковать: GitHub не распаковывает загруженный ZIP в сайт.
3. Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
4. Дождаться публикации. Ожидаемый адрес для аккаунта smuzoo: https://smuzoo.github.io/portfolio/ . Этот адрес станет рабочим после публикации, он не подтверждает текущее размещение.

## Редактирование

- index.html — основные тексты и структура разделов.
- content.js — ссылки и музыкальные проекты.
- styles.css — оформление, цвета и адаптация для телефона.
- assets/ — фотографии, скрины, музыка и видео.
- portfolio.pdf — короткое портфолио для скачивания.

Относительные пути позволяют разместить сайт как в корне домена, так и в подпапке репозитория.

## Просмотр локально

Из этой папки выполнить:

```sh
python3 -m http.server 8765
```

Открыть http://127.0.0.1:8765/ .
